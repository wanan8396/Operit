# 紧凑用量浮层与持久化平均值

- 右上角原有 token 圆环作为入口，点击后显示锚定该入口的 DropdownMenu，不再居中弹出 AlertDialog。
- 浮层宽度 180–260dp，保留上下文、累计入/出、总计、平均速率和平均首字六行；移除首字下说明及关闭按钮。点击外部或返回关闭。
- 当前会话内成功完成的主模型请求分别计算速率和首字延迟的算术平均；失败/取消及未记录指标不计入，子任务和工具时间不计入。模型 hop 是各自完整模型请求。
- 只保存统计总和与计数，不保存消息或单调时钟。App 冷启动加载专用 SharedPreferences，完成请求时用 apply 保存，删除会话清理对应记录。
- 展开时立即读取一次快照，随后每秒读取一次；不会订阅每 Token 更新的 sessions。所有六行使用同一快照；关闭后取消计时。新请求进行中保留已有历史平均值，完成后进入统计。
- 旧版本未持久化数据不能凭空恢复；升级后首个有效成功请求建立平均值，缺失数据仍显示未记录。
