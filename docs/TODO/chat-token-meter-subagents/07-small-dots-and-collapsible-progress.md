# 精细三点状态与可折叠子任务

## 当前实现

对话区子任务不再使用状态圆圈。运行和重试使用三个直径 2.5dp 的小点，整体占位 14dp，900ms 周期依次明暗脉动，不跳动、不改变行高。成功使用与计划项一致的 14dp `CheckCircle` 和主题 tertiary 色；失败、超时与取消使用各自终态图标，不呈现为成功或持续加载。

增加“数量 · 子智能体”标题，直接复用思考与工具组的 `CanvasExpandableHeaderRow`。默认展开，点击标题收起或展开；箭头旋转 300ms，内容淡入淡出 200ms。折叠状态使用聊天 ID 与首个任务 ID 记忆，当前轮次工具更新不会重开手动收起的列表。

标题箭头使用原工具正文起点，子任务状态指示器使用共享标题起点 24dp 缩进，与箭头右侧数量文字对齐。任务名称用计划同款 bodySmall，名称下方状态与工具活动用 labelSmall。

不恢复输入框入口，不修改进度 Store 或终态收尾策略：某任务先完成时在同轮列表显示勾选，全部任务终态后对话区投影移除，后续工具流不被阻挡。结束任务仍可在已有顶部计划菜单中查看。
