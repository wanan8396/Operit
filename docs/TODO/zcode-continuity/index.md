# ZCode 连续性第一批

## 原状、目标与范围

计划和模型阶段原来仅在进程中保留；页头用量统计不能解释请求上下文来源或摘要覆盖范围；模型缺少有预算和引用的当前会话历史读取入口。

本批增量实现三项连续性能力：计划及阶段原子持久化与请求边界恢复、请求与压缩诊断、带来源引用的当前会话历史提取。保持既有计划工具和页头统计接口，不引入跨会话读取或远程检索。

## 步骤

- [01 会话计划持久化](01-plan.md)
- [02 上下文诊断](02-context.md)
- [03 当前会话历史检索](03-history.md)
- [04 选定聊天模型与精简页头](04-selected-model-and-header.md)

## 当前状态

三项功能的代码、接线、中文及英文资源和测试源码已落地。首次 GitHub Actions 编译发现历史工具参数校验将可空异常消息传入非空字段，Debug 和 Release 均未通过 Kotlin 编译；已修复并补充校验回归用例，详见 [03 当前会话历史检索](03-history.md)。新一轮远程编译、自动化测试及设备集成行为尚待验证，不能据此宣称运行验收通过。

工作区内另外存在权限队列和子代理相关改动，不属于本批三项能力的运行验收范围。后续集成需验证重启恢复、模型阶段切换、摘要后续聊、历史预算与拒绝跨会话参数、会话删除后的清理。

## 后续增量

[04](04-selected-model-and-header.md) 取消计划阶段模型路由，以聊天选择为准；用量弹窗精简为概览并补充请求性能，全轮子智能体结束后从页头隐藏。该增量覆盖前文的阶段切换和诊断弹窗说明，计划持久化、诊断采集与历史工具不变。
