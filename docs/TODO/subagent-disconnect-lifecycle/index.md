# 子智能体断线与父会话生命周期

## 原状与根因

子智能体进度仅由每个子任务的 finally 收尾。父会话取消、异常或结束时，没有独立的执行级进度收尾入口。迟到的 retry 与 beginAttempt 回调还可以把终态改回活动态，对话尾部因而可能继续显示旧任务，直到新委派轮次清空面板。

工具执行使用持久 CoroutineScope.async。该作用域不属于收集父流的协程树，一次未处理异常也可能永久取消它，使后续工具批次不再正常执行。子任务已有的重试和续接逻辑本次保留。

## 修复范围

- 给每个收集中的父会话执行分配 executionId，传入原生工具运行上下文。多个模型 hop 和子任务重试共用同一个执行所有权。
- 取消、最终收尾和不可恢复异常只终结对应父执行的活动子任务及未完成工具，保留已完成结果。
- 旧执行收尾不能取消重连后的新执行；旧轮次不能重新启动子任务；终态不接受迟到的重试、开始尝试或结束回调。
- ToolExecutionScope 将 IO 工具批次保留在调用者协程树内；显式取消只影响当前批次，下一次执行仍可用。手动记忆写入保持独立异步行为。
- Socket closed 只有在执行上下文已明确取消时才按正常取消处理。活动执行丢失连接时，不把部分模型输出当作完成后的工具指令执行。
- 对话中的重试行显示已有本地化状态和尝试编号，不再只有无说明的加载动画。

不改工具参数、模型映射、计划路由、无限重试策略或历史续接格式，不根据瞬时 UI Idle/Completed 状态结束子任务。
